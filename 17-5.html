JavaScript 定时器

刘庭轩

setTimeout一次性

延迟指定毫秒后执行一次回调函数。常用于延迟提示、动画延迟、一次性轮询等。

let t = setTimeout(fn, 1000);
clearTimeout(t); // 取消

setInterval循环

每隔指定毫秒反复执行回调，直到手动停止。常用于时钟、轮播、定时器、定时轮询等。

let t = setInterval(fn, 1000);
clearInterval(t); // 取消

清除方法别搞混

setTimeout → clearTimeout
setInterval → clearInterval

ID 是数字

两个定时器的 ID 都是 number，可以互相混用同一个变量，因为 clearTimeout(intervalId) 实际上也能停掉 interval，但建议分类使用以免读代码的人糊涂。

页面关闭会自动清理

浏览器关闭标签页/刷新后，所有定时器都会被杀掉，不会在后台继续跑。
